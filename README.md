# FullDev School — Documentação

Este é o repositório oficial de documentação do projeto FullDev School.

Aqui ficam centralizados os registros e materiais de referência do projeto, como atas de reuniões, links oficiais, recursos utilizados pela equipe e demais documentações que venham a ser criadas futuramente.

O objetivo deste repositório é permitir que qualquer participante encontre rapidamente as informações essenciais do FullDev School.
