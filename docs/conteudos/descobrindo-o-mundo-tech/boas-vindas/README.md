# Página de boas-vindas

Página inicial do curso no Canvas: é a primeira tela que o estudante vê ao entrar. Dá as boas-vindas à trilha Descobrindo o Mundo Tech e resume os seis módulos.

- Código da página: [`boas-vindas.html`](./boas-vindas.html)
- No Canvas: [Boas-vindas — Descobrindo o Mundo Tech](https://canvas.eureka.ia.br/courses/1/pages/boas-vindas-descobrindo-o-mundo-tech), definida como página inicial do curso.

## Links dos módulos

Cada cartão de módulo ganha um botão de acesso quando o módulo é publicado no Canvas. Hoje têm botão o Módulo 3 (Aula 1) e o Módulo 5 (página de introdução).

Para adicionar o botão de outro módulo, copie o parágrafo do botão de um cartão que já tem link, cole no fim do cartão do seu módulo e troque o endereço, o texto e a cor.

## Como atualizar

1. Edite `boas-vindas.html` neste repositório.
2. No Canvas, abra a página, clique em **Editar**, abra o editor de HTML e substitua todo o conteúdo pelo arquivo.
3. Salve.

Edite sempre o arquivo do repositório primeiro. Mudanças feitas só no Canvas se perdem na próxima atualização.
