## Aula 1 — Computação em nuvem

**Itens da ementa:** servidores; data centers; processamento remoto; armazenamento remoto; conceito de computação em nuvem.

**Ideias principais**

- Um servidor é um computador que fica ligado o tempo todo para atender pedidos de outros computadores.
- Data centers são prédios com milhares de servidores, energia e refrigeração próprias.
- Na nuvem, o processamento e o armazenamento acontecem nos computadores de outra empresa, e não no seu.
- "Nuvem" é o nome para usar esses recursos pela Internet, pagando pelo que usa, sem precisar comprar e manter as máquinas.
- A diferença entre Software como Serviço (SaaS), Plataforma como serviço (PaaS), Infraestrutura como serviço (IaaS): usar um programa pronto (ex.: Gmail, Netflix), usar uma plataforma (ex.: Vercel, Heroku) ou alugar a máquina (ex.: AWS EC2, Google Compute Engine).

**Exercícios:** listar cinco serviços usados no dia a dia e marcar onde os dados ficam guardados (no aparelho, na nuvem ou nos dois); diferenciar armazenamento local e remoto; identificar o que é um data center.

## Aula 2 — Segurança digital

**Itens da ementa:** A tríade CID (Confidencialidade, Integridade, Disponibilidade); boas práticas básicas de segurança digital; pentesting; blue team; frameworks e conformidade a leis.

**Ideias principais**

- Autenticação responde "quem é você?" (senha, código, biometria).
- Autorização responde "o que você pode fazer?" (permissões diferentes para usuários diferentes).
- Ameaças comuns: senhas fracas ou repetidas, golpes por mensagem (phishing) e vazamento de dados.
- Boas práticas: gerenciador de senhas, verificação em duas etapas, atualizações e desconfiança de links recebidos.
- Como um agente mal-intencionado age? Como realizar testes que mimetizem sua atuação? Como se defender de ataques?
- LGPD e leis relacionadas.

**Exercício:** relacionar corretamente a tríade CID com seus conceitos; revisar a segurança de uma conta pessoal (verificação em duas etapas, senha única, dispositivos conectados); identificar uma mensagem suspeita.

**Materiais complementares:** criptografia; segurança física.

## Aula 3 — Tecnologia além dos computadores tradicionais

**Itens da ementa:** sistemas embarcados; Internet das Coisas; automação; dispositivos inteligentes.

**Ideias principais**

- Sistemas embarcados são computadores pequenos dentro de outros aparelhos, feitos para uma tarefa específica.
- Sensores leem o ambiente (temperatura, movimento, luz) e atuadores agem sobre ele (motor, lâmpada, trava).
- Internet das Coisas é quando esses aparelhos se conectam à Internet para enviar dados ou receber comandos.
- Automação é fazer uma tarefa acontecer sozinha a partir de uma regra: "se acontecer X, faça Y".
- Dispositivos inteligentes combinam sensores, conexão e regras ou IA.

**Exercício:** escolher um aparelho da casa e identificar entrada (sensor), processamento, saída (atuador) e se ele se conecta à Internet; montar um sistema simples de "se, então".

## Aula 4 — Aplicações contemporâneas

**Itens da ementa:** aplicações Web; aplicações móveis; Inteligência Artificial; implicações para a privacidade.

**Ideias principais**

- Aplicações Web rodam no navegador; aplicações móveis são instaladas no celular e usam recursos do aparelho (câmera, GPS, notificações).
- Aplicativos nativos, híbridos e Web: diferença em nível introdutório.
- Inteligência Artificial: sistemas que aprendem padrões a partir de dados para reconhecer, prever ou gerar conteúdo.
- IA no dia a dia: recomendações, tradução, reconhecimento de voz e assistentes de texto; limites como erros e vieses.
- Aplicações modernas juntam tudo: um app no celular conversa com servidores na nuvem, usa IA e pode controlar dispositivos IoT.
- Coleta de dados e privacidade.

**Exercício:** identificar aplicativos nativos, híbridos, web; compreender o levantamento de dados realizado por aplicações modernas e as implicações para a privacidade.
