# Ementas

Esta pasta reúne as ementas das trilhas formativas do FullDev School.

As ementas descrevem objetivo geral, objetivos específicos, módulos, conteúdos programáticos, atividades integradoras e resultados de aprendizagem. Elas funcionam como referência pedagógica para a criação de aulas, materiais, atividades e trilhas técnicas posteriores.

## Organização

Cada ementa deve ficar em um arquivo Markdown próprio, usando nomes descritivos em letras minúsculas e separados por hífen:

```text
docs/ementas/nome-da-trilha.md
```

## Como adicionar uma nova ementa

1. Copie o modelo disponível em [templates/ementa.md](../../templates/ementa.md).
2. Crie o arquivo dentro de `docs/ementas/`.
3. Use um nome claro, seguindo o padrão `nome-da-trilha.md`.
4. Adicione o link da nova ementa neste índice.
5. Atualize o [README principal](../../README.md), quando a trilha precisar aparecer no acesso rápido ou na lista geral de documentação.
