# Atas de reuniões

As atas registram os principais pontos discutidos nas reuniões do FullDev School, incluindo participantes, assuntos tratados, decisões quando existirem e próximos passos.

Elas ajudam a manter o histórico do projeto acessível para participantes atuais e novos integrantes.

## Organização

As atas ficam organizadas por ano e mês:

```text
docs/atas/AAAA/MM/
```

Exemplo:

```text
docs/atas/2026/09/
```

## Como adicionar uma nova ata

1. Copie o modelo disponível em [templates/ata.md](../../templates/ata.md).
2. Crie o arquivo dentro da pasta do ano e mês correspondentes.
3. Use o padrão de nomenclatura definido abaixo.
4. Adicione o link da nova ata neste índice.

## Padrão de nomenclatura

Use o formato:

```text
AAAA-MM-DD-nome-da-reuniao.md
```

Exemplo:

```text
2026-09-03-reuniao-inicial.md
```
